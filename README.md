# AI Study Assistant (NotebookLLM for Students)

An AI-powered document intelligence and study companion designed to help students learn faster from PDFs, textbooks, and lecture notes. Similar to NotebookLM, this tool allows users to upload documents, ask context-aware questions, extract summaries, and simplify complex academic concepts.

---

##  Key Features (Planned & In Progress)
- **PDF & Document Upload:** Upload course notes, research papers, and textbooks.
- **Contextual Q&A:** Ask questions grounded strictly in the provided documents.
- **Smart Summarization:** Generate instant study guides, key takeaways, and flashcard-style concepts.
- **Interactive Chat Interface:** Clean, focused workspace tailored for study sessions.

---

## 🛠️ Tech Stack
- **Frontend:** React, Vite, CSS
- **Backend:** Node.js, Express
- **AI / Document Processing:** LLM Integration, PDF Parsing (In Development)
